# LTspice软件介绍
- 在众多的电路仿真软件中，我是非常推荐LTspice这个软件的，他虽然不像Multisim一样有丰富的电路组件和优秀的图形化界面，而LTspice却做的非常专一，没有多的花里胡哨的界面，而是只有仿真中最需要展示数据，并且他的功能也丝毫不逊Multisim，做一些分立元件电路的验证非常好用，而特定IC芯片的电路仿真得需要找来对应的器件模型
